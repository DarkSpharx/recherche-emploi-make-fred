# Automatiser sa recherche d'emploi Data Analyst

Ce dépôt rassemble les livrables du projet d'automatisation avec Make et l'API JSearch (OpenWeb Ninja).

## Livrables

- [`presentation.txt`](presentation.txt) — version de référence suivie par Git.
- `presentation.docx` — copie personnelle ignorée par Git; la tenir à jour avec le fichier texte.
- [`scenario.json`](scenario.json) — Blueprint Make final, avec les secrets remplacés par `***`.
- [`captures/`](captures/README.md) — emplacement des captures d'écran du scénario, du tableau, des alertes Discord et de la planification.

## Avant de publier

Avant publication, vérifiez que les captures et le document ne contiennent aucun mot de passe, clé, webhook ou renseignement personnel.

Le Google Sheet doit être partagé en lecture seule et son lien ajouté au document de présentation. Ne placez aucune clé API ni URL de webhook dans ce dépôt.
